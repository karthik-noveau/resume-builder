Resume Studio — UI Prototype

The approved UI, as static HTML. Every screen below is reachable, navigable and responsive. No build step, no server, no dependencies — open any file directly in a browser.

Each page carries a navigation bar across the top, so you can move between screens without returning here. Interactions are UI-only (theme toggle, tabs, dialogs, drawers, dropdowns); there is no application logic behind them. React implementation must match these screens — if a design needs to change, change it here first.
